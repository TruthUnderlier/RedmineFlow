## First-time setup

<Steps>

1. Run the login wizard and point it at your Redmine server:

   ```bash
   rdflow auth login
   ```

2. Confirm you are wired up:

   ```bash
   rdflow auth status
   ```

3. Start driving issues, time entries, and more.

</Steps>

## Issues

<Tabs syncKey="issue-verb">
  <TabItem label="List">
    ```bash
    rdflow issues list --project myproject
    rdflow issues list --assignee me --status open
    ```
  </TabItem>
  <TabItem label="View">
    ```bash
    rdflow issues get 123
    ```
  </TabItem>
  <TabItem label="Create">
    ```bash
    rdflow issues create \
      --project myproject \
      --subject "Fix login bug" \
      --tracker Bug
    ```
  </TabItem>
  <TabItem label="Update">
    ```bash
    rdflow issues update 123 --status "In Progress" --assignee me
    ```
  </TabItem>
  <TabItem label="Close">
    ```bash
    rdflow issues close 123 --notes "Fixed in commit abc123"
    ```
  </TabItem>
  <TabItem label="Browse">
    ```bash
    rdflow issues browse --project myproject
    ```
  </TabItem>
</Tabs>

## Time tracking

```bash
# interactive
rdflow time log

# one-shot
rdflow time log --issue 123 --hours 2.5 --activity Development --comment "Code review"

# today's entries
rdflow time list --user me --from today
```

## Search

```bash
rdflow search "login bug"
rdflow search issues "login bug" --project myproject
rdflow search "login bug" --open-issues
```

## Name resolution

<Badge text="no IDs required" variant="tip" />
You do not need to memorise numeric IDs. The CLI resolves trackers, statuses, priorities, projects, and users by name.

```bash
rdflow issues create \
  --project myproject \
  --tracker Bug \
  --priority High \
  --assignee "John Smith"

rdflow issues list --assignee me
```

<Aside type="tip" title="The `me` keyword">
  `me` always resolves to the current user of the active profile — handy in scripts that run under different accounts.
</Aside>

User and group names given to `--assignee` are matched against the project's members first, so they resolve without admin rights. Use `--assignee none` to unassign an issue or to list unassigned issues. See [assignee resolution](/commands/issues/#assignee-resolution).

## Output formats

```bash
rdflow issues list                # table (default)
rdflow issues list -o json        # machine-readable output
rdflow issues list --jq '.[].id'  # filter JSON (built-in jq)
rdflow issues list -o json --jq '.[] | [.id, .subject] | @csv'  # CSV for spreadsheets
```

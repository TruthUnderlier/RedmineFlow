## Install

<Tabs syncKey="installer">
  <TabItem label="Homebrew" icon="apple">
    macOS and Linux. Includes shell completions.

    ```bash
    brew install TruthUnderlier/tap/rdflow
    ```
  </TabItem>

  <TabItem label="Install script" icon="seti:shell">
    macOS and Linux. Installs to `~/.local/bin`.

    ```bash
    curl -fsSL https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.sh | REDMINE_CLI_SKIP_ATTESTATION=1 bash
    ```
  </TabItem>

  <TabItem label="PowerShell" icon="seti:powershell">
    Windows. Installs to `%LOCALAPPDATA%\Programs\rdflow` and adds it to your `PATH`.

    ```powershell
    $env:REDMINE_CLI_SKIP_ATTESTATION='1'; irm https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.ps1 | iex
    ```
  </TabItem>

  <TabItem label="Manual" icon="download">
    Download the archive for your platform from [GitHub Releases](https://github.com/TruthUnderlier/RedmineFlow/releases/latest) and put `rdflow` on your `PATH`.
  </TabItem>
</Tabs>

Check that it works, then [log in](/getting-started/configuration/):

```bash
rdflow --version
```

## Update

```bash
rdflow update
```

Homebrew installs are updated with `brew upgrade`. See [self-update](/commands/other/#self-update) for details.

## Script options

Both install scripts verify the release checksum, and the build attestation when a logged-in [GitHub CLI](https://cli.github.com) is installed. rdflow releases do not carry build attestations yet, so the commands on this page set `REDMINE_CLI_SKIP_ATTESTATION=1`; without it, the install fails on a machine with a logged-in GitHub CLI. Set these environment variables before running a script:

| Variable | Effect |
|---|---|
| `REDMINE_CLI_VERSION` | Install a specific release, e.g. `v10.0.1` |
| `REDMINE_CLI_SKIP_ATTESTATION=1` | Skip the attestation check (not recommended) |
| `REDMINE_INSTALL_DIR` | Install to another directory |
| `REDMINE_CLI_NO_MODIFY_PATH=1` | PowerShell only: leave `PATH` unchanged |

The variable goes to the shell that runs the script, not to `curl`:

```bash
curl -fsSL https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.sh | REDMINE_CLI_VERSION=v10.0.1 REDMINE_CLI_SKIP_ATTESTATION=1 bash
```

```powershell
$env:REDMINE_CLI_VERSION = 'v10.0.1'; $env:REDMINE_CLI_SKIP_ATTESTATION = '1'; irm https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.ps1 | iex
```

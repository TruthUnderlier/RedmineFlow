## 安装

<Tabs syncKey="installer">
  <TabItem label="Homebrew" icon="apple">
    适用于 macOS 和 Linux，包含 shell 补全。

    ```bash
    brew install TruthUnderlier/tap/rdflow
    ```
  </TabItem>

  <TabItem label="安装脚本" icon="seti:shell">
    适用于 macOS 和 Linux，安装到 `~/.local/bin`。

    ```bash
    curl -fsSL https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.sh | REDMINE_CLI_SKIP_ATTESTATION=1 bash
    ```
  </TabItem>

  <TabItem label="PowerShell" icon="seti:powershell">
    适用于 Windows，安装到 `%LOCALAPPDATA%\Programs\rdflow` 并加入 `PATH`。

    ```powershell
    $env:REDMINE_CLI_SKIP_ATTESTATION='1'; irm https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.ps1 | iex
    ```
  </TabItem>

  <TabItem label="手动安装" icon="download">
    从 [GitHub Releases](https://github.com/TruthUnderlier/RedmineFlow/releases/latest) 下载适合你平台的压缩包，并将 `rdflow` 放到 `PATH` 中。
  </TabItem>
</Tabs>

确认可以运行，然后[登录](/zh-cn/getting-started/configuration/)：

```bash
rdflow --version
```

## 更新

```bash
rdflow update
```

通过 Homebrew 安装时使用 `brew upgrade` 更新。详见[自更新](/zh-cn/commands/other/#自动更新)。

## 脚本选项

两个安装脚本都会校验发布版本的校验和；若安装了已登录的 [GitHub CLI](https://cli.github.com)，还会验证构建证明。rdflow 的发布版本目前还没有构建证明，所以本页的命令都设置了 `REDMINE_CLI_SKIP_ATTESTATION=1`；不加的话，在已登录 GitHub CLI 的机器上安装会失败。运行脚本前可设置以下环境变量：

| 变量 | 作用 |
|---|---|
| `REDMINE_CLI_VERSION` | 安装指定版本，例如 `v10.0.1` |
| `REDMINE_CLI_SKIP_ATTESTATION=1` | 跳过构建证明检查（不推荐） |
| `REDMINE_INSTALL_DIR` | 安装到其他目录 |
| `REDMINE_CLI_NO_MODIFY_PATH=1` | 仅 PowerShell：不修改 `PATH` |

变量要传给运行脚本的 shell，而不是 `curl`：

```bash
curl -fsSL https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.sh | REDMINE_CLI_VERSION=v10.0.1 REDMINE_CLI_SKIP_ATTESTATION=1 bash
```

```powershell
$env:REDMINE_CLI_VERSION = 'v10.0.1'; $env:REDMINE_CLI_SKIP_ATTESTATION = '1'; irm https://raw.githubusercontent.com/TruthUnderlier/RedmineFlow/main/install.ps1 | iex
```
